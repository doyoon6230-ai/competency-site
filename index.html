NCS·O*NET 기반 역량 모델과 평가 문항

NCS 직업기초능력과 O*NET 스킬·업무스타일을 교차해 6개 핵심 역량을 뽑고, 역량별 행동지표와 샘플 문항을 붙였습니다. 평가 대상은 신입~실무자급 사무직입니다.

초안행동지표와 문항은 NCS·O*NET의 공식 문항이 아니라 프로젝트용으로 새로 작성했습니다. 신뢰도·타당도 검증 전이므로 시스템 개발·테스트용으로만 쓰고, 실제 평가에는 에프엔이노에듀 자료로 교체하세요.

역량 모델 개요

NCS 10개 직업기초능력 가운데 행동으로 관찰할 수 있고 시나리오 문항으로 측정하기 쉬운 6개를 골랐습니다. 수리·정보·기술·조직이해는 지식형 시험에 가까워 1차 범위에서 뺐습니다.

O*NET 업무스타일(Work Styles) 항목은 최근 개편됐을 수 있으니 명칭을 O*NET Content Model에서 다시 확인해야 합니다.

3수준 행동지표

각 역량을 1 미흡 · 2 기대 충족 · 3 우수로 나눠 관찰 가능한 행동으로 적었습니다. 자동 채점과 리포트의 채점 근거 문장이 모두 이 표에서 나옵니다.

평가 구성

유형문항 수측정 역량채점
상황판단검사(SJT)6C1~C6 각 1문항선택지별 0~3점 자동 채점
서술형 인바스켓1C1 · C3 · C4루브릭 4요소 × 1~3점, 평가자 또는 LLM 채점 · 권장 20분
응시자 화면 · 점수와 채점 근거는 숨김

역량 진단 검사

각 상황에서 가장 적절한 행동 1개를 고르세요. 답안은 고를 때마다 이 브라우저에 저장되어 창을 닫아도 남습니다.

답안지

평가자 화면 · 역량별 점수 = 문항 점수 합 ÷ 만점 × 100

역량 진단 리포트

예시 응답으로 계산한 리포트입니다

역량별 채점 근거

인바스켓 채점

평가자가 루브릭을 보고 요소별 점수를 매기면 위 역량 점수에 바로 반영됩니다. 답안이 비었거나 해당 메일을 다루지 않으면 0점입니다.

개발 메모

시스템 설계

문항을 그대로 DB에 넣을 수 있도록 역량 → 문항 → 선택지 → 응답 구조로 나눕니다.

테이블 구조

테이블주요 필드비고
competencycode(C1~C6), name, definition, ncs_ref, onet_ref, level1~3 행동지표리포트의 채점 근거 문장 출처
itemid, competency_code, type(SJT/서술형), scenario, rubric고객사·직급 태그를 두면 문항 은행으로 확장 가능
optionitem_id, label(A~D), text, score(0~3), rationalescore·rationale은 응시자 API 응답에서 제외
responseattempt_id, item_id, selected_option 또는 answer_text, saved_at문항마다 즉시 저장해 창을 닫아도 답안 유지
scoreattempt_id, item_id, score, evidenceSJT는 option에서 복사, 서술형은 LLM 결과와 인용문 저장

채점과 리포트 흐름

  1. 응시자가 제출하면 SJT는 선택지 점수를 즉시 기록한다.
  2. 서술형은 루브릭을 포함한 프롬프트로 채점하고 점수와 인용문을 저장한다. LLM에는 점수의 근거가 된 답안 문장을 그대로 인용하도록 요구한다.
  3. 역량별 점수 = 해당 역량 문항 점수 합 ÷ 만점 × 100으로 환산한다.
  4. 리포트에 역량별 점수, 해당 수준의 행동지표, 문항별 채점 근거를 함께 출력한다.
